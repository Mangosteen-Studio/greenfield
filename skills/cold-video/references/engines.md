# Assemble generated footage into the final video

Runway or fal.ai supplies the paid generated footage. These tools handle the final sequence, exact product captures, titles, captions and sound; they do not replace the provider workflow.

Reviewed October 7, 2026. Provider details change; verify current official docs when invoking them.

## HyperFrames

Default when available for a new video. Load the installed entrypoint, route by deliverable and read core/CLI plus relevant animation/audio guidance. Build a native timed composition, not arbitrary HTML with a filename changed. HyperFrames owns clip and media playback; the animation runtime controls visual state. Use finite, seekable timelines and ship required assets. Run checks, render and inspect the result. https://hyperframes.heygen.com/ ; https://github.com/heygen-com/hyperframes/blob/main/packages/core/docs/core.md

## Remotion

Use when requested or an existing source project already uses it. Map shots to sequences with explicit frame ranges; derive transforms/opacity from frame state and preserve input props for buyer variants. Keep render-time data frozen and assets local. Read current rendering and licensing requirements. Validate the real video, not just the React preview. https://www.remotion.dev/docs/ai/skills ; https://www.remotion.dev/docs/use-current-frame

## Storylane

Borrow authentic product context, focused guided steps and clear hotspots. Use an existing authorized Storylane capture/export if supplied, respecting its actual capabilities. This skill does not have a Storylane connector and does not promise automatic HTML cloning. https://docs.storylane.io/recording-demos/recording-html-demos

## No renderer available

Complete script, storyboard, sources, shot list, poster and draft captions. State that rendering remains unavailable and identify the dependency. Ask only if installing, paid usage or external action needs authorization; otherwise proceed with an appropriate available renderer. Never claim that the preparation script renders a video.
